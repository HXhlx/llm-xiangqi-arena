# Board / piece art

This public tree ships **one** licensed set (CC0-1.0 themes from [xiangqi-setup](https://github.com/hartwork/xiangqi-setup)):

| Path | Role |
|------|------|
| `cc0/xiangqi-setup/board/minimal_chinese/` | Board SVG |
| `cc0/xiangqi-setup/pieces/retro_simple/` | Piece SVGs |

Each folder includes `LICENSE.txt` / `LICENSE.json`. The match server does not require these files; they are here so a UI or diagram tool can render a complete, redistributable set.

The traditional 9×10 / river / palace geometry is a cultural convention, not a vendor catalog.
